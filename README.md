# Tony-Montezuma-Gold-PUBLIC
Tony Montezuma's Gold – public, demo version of the game for the 8-bit Famicom/NES consoles

It is with great satisfaction that I share the news that after many months of tinkering with C/Assembler code, the full version of "Tony Montezuma's Gold" has been created for the 8-bit NES/Famicom platform.

This is a project inspired by classic platformers, where we focused on aspects that were once most important:
* Challenging yet satisfying gameplay.
* Distinctive pixel art visuals.
* Classic-inspired soundtrack.

Download & play 🎮 our demo from https://monochrome-productions.itch.io/tony-montezumas-gold-nes

And if you like it, I encourage you to purchase it :)
